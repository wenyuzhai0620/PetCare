# 宠物照护记录微信小程序

一个原生微信小程序示例，用于记录猫狗的日常照护：

- 宠物档案：添加、编辑猫或狗
- 健康判断：支持输入文字或上传图片/视频，按症状给出可能疾病方向、用药讨论清单、检查优先级和信息来源
- 快捷记录：内驱虫、外驱虫、洗澡；狗狗可记录遛狗开始时间、时长和便便状态，默认每日遛狗 2 次并可自定义
- 记录时间：每次记录时通过滚轮选择上次发生日期，并据此计算下次事项
- 手动记录：选择类型、上次发生日期并添加备注
- 今日概览：统计当天各类记录次数
- 下次事项：按常见周期提示内驱虫、外驱虫、洗澡、遛狗
- 自定义周期：内驱虫默认 90 天，外驱虫默认 30 天；猫洗澡默认 180 天，狗洗澡默认 30 天，并可在宠物档案中修改
- 本地存储：使用 `wx.setStorageSync` 保存数据

## 运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹：`/Users/zhaiwenyu/Documents/PetCare`。
4. AppID 可使用测试号或自己的小程序 AppID。
5. 点击编译预览。

## 主要文件

- `app.json`：小程序全局配置
- `pages/index/index.wxml`：首页结构
- `pages/index/index.js`：记录、统计、本地存储逻辑
- `pages/index/index.wxss`：页面样式
